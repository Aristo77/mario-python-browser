#### Description:

**Mario Python Browser** is a web-based application that generates the classic Mario pyramid dynamically in a web browser using Python and Flask. This project is inspired by the Mario problem from Week 1 of CS50 (originally implemented in C) and demonstrates the progression from command-line programming to web-based application development. The goal of this project is to show how fundamental programming concepts—such as variables, functions, loops, and conditions—can be applied in a modern web environment.

This application allows a user to input a height value through a web form and then renders a Mario-style pyramid pattern directly in the browser. Instead of printing output to the terminal, the program sends data from the Python backend to an HTML template, which displays the result visually. This transformation from console output to browser rendering reflects the broader journey in CS50 from basic programming to full web development.

## Features

The Mario Python Browser application includes the following features:

1. **User Input via Web Form**
   Users can enter a numeric value representing the height of the pyramid.

2. **Input Validation**
   The program checks whether the input is valid and ensures that the value falls within an acceptable range.

3. **Dynamic Pyramid Generation**
   The pyramid is generated using Python logic and displayed in the browser.

4. **Separation of Logic and Presentation**
   The application separates backend logic (Python) from frontend presentation (HTML templates).

5. **Reusable Functions**
   The pyramid-generation logic is implemented as a function that can be reused or modified easily.

6. **Web-Based Interface**
   The application runs in a browser instead of a terminal, making it more user-friendly.

## File Structure

The project directory contains the following files:

```
mario-python-browser/
│
├── app.py
├── mario.py
│
└── templates/
        index.html
```

### app.py

This file is the main entry point of the application. It initializes the Flask web server, defines the routes, and handles user requests. When a user submits a height value through the web form, `app.py` receives the input, calls the pyramid-generation function, and passes the result to the HTML template.

Key responsibilities of `app.py` include:

* Starting the Flask application
* Handling HTTP requests
* Processing form input
* Rendering templates

### mario.py

This file contains the core logic for generating the Mario pyramid. The function in this file uses loops and string manipulation to build the pyramid line by line.

Separating this logic into its own file improves readability and maintainability. It also follows good software design principles by keeping the business logic independent from the web framework.

### templates/index.html

This file defines the user interface of the application. It contains the HTML form where users enter the height value and displays the generated pyramid.

The template uses Jinja syntax to insert dynamic content generated by Python. This demonstrates how backend data can be rendered in a web page.

## How the Program Works

The program follows a simple workflow:

1. The user opens the web application in a browser.
2. The user enters a number representing the pyramid height.
3. The browser sends the input to the Flask server.
4. The server calls the pyramid-generation function.
5. The function creates the pyramid pattern.
6. The server sends the result back to the browser.
7. The browser displays the pyramid on the page.

This process demonstrates the interaction between client and server, which is a fundamental concept in web development.

## Design Decisions

Several design decisions were made during development.

### Using Flask Instead of a Command-Line Program

Originally, the Mario pyramid problem was implemented as a command-line program. However, converting it into a web application provides a more modern and interactive user experience. It also demonstrates how simple algorithms can be integrated into web systems.

### Separating Logic Into a Dedicated Module

The pyramid-generation function was placed in `mario.py` instead of `app.py`. This separation improves code organization and makes it easier to test and reuse the function.

### Using Templates for Output

Instead of printing output directly, the program uses HTML templates. This approach allows the application to display results in a structured and visually appealing format.

---

## Challenges Encountered

One challenge during development was converting terminal-based output into a format suitable for web display. In a command-line program, text is printed line by line, but in a web application, the output must be formatted as HTML.

Another challenge was handling user input validation. The program needed to ensure that the input was numeric and within a reasonable range. This required implementing conditional logic and error handling.

These challenges provided valuable learning experiences and helped reinforce programming fundamentals.

## Installation and Usage

To run this project locally, follow these steps:

1. Download the project files.
2. Navigate to the project directory.
3. Install Flask if necessary.
4. Run the application.
5. Open the browser.

Example commands:

```
wget https://github.com/Aristo77/mario-python-browser/archive/refs/heads/main.zip
unzip main.zip
cd mario-python-browser-main
export FLASK_APP=app.py
flask run
```

Then open:

```
http://127.0.0.1:5000
```
